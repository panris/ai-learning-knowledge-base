# Hermes Agent 技能系统与自改进机制

## 技能（Skill）概述

技能是 Hermes 的插件单元，每个技能定义了一个可复用的任务能力。技能在 `~/.hermes/hermes-agent/skills/` 目录下以目录形式存在。

## 技能结构

每个技能目录包含：

```
skill-name/
├── SKILL.md          # 技能元数据（必需）
├── scripts/          # 执行脚本（Python/Bash 等）
├── data/            # 运行时数据
└── README.md        # 可选说明
```

### SKILL.md 示例结构

```yaml
name: skill-name
description: 技能描述（用于 Agent 理解何时调用）
trigger_keywords: [触发词1, 触发词2]
capabilities:
  - 能力1
  - 能力2
```

## 内置核心技能

### self-improving

自我反思技能，Agent 在以下情况自动触发：
- 工具/API 调用失败
- 用户纠正 Agent 输出
- Agent 发现知识过时或错误
- 发现更优方案

工作流：评估工作 → 捕获错误 → 更新记忆 → 记录教训

### coding-agent

代码任务委派技能，支持：
- 从头构建新功能/应用
- PR Review（在临时目录执行）
- 重构大型代码库
- 迭代式编码（需文件探索）

内部使用 Codex、Claude Code 或 Pi agent，通过 RPC 调用。

### session-logs

会话历史搜索技能：
- 使用 jq 语法检索压缩后的会话历史
- 支持正则和全文搜索
- 可跨会话检索上下文

### memory

记忆系统技能，提供：
- `memory_search`：语义检索记忆文件
- `memory_get`：读取指定记忆片段
- 自动记忆写入钩子

## 自改进循环

```
任务执行 → 结果评估
    ↓
是否需要创建/更新技能？
    ↓
是 → 生成 SKILL.md 骨架
    ↓
使用中持续优化 → 持久化记忆
```

### 触发条件

- 任务复杂度 > 阈值（Agent 自动判断）
- 重复出现的任务模式
- 用户明确提出扩展需求

### 优化策略

1. **即时优化**：当前会话中发现问题立即修正
2. **持久化优化**：跨会话保留学习到的模式
3. **技能自进化**：技能运行时根据结果调整内部逻辑

## 自定义技能开发

### 创建步骤

1. 规划技能职责和触发词
2. 创建目录结构
3. 编写 SKILL.md 元数据
4. 实现脚本逻辑
5. 测试运行

### 示例：天气技能

```
weather/
├── SKILL.md
└── scripts/
    └── weather.py
```

### SKILL.md 内容：

```yaml
name: weather
description: 查询天气和预报
trigger_keywords: [天气, weather, 温度, 穿衣]
capabilities:
  - 查询当前天气
  - 未来7天预报
  - 穿衣建议
```

## 技能注册

Hermes 启动时自动扫描 skills 目录并注册所有技能：

```bash
ls ~/.hermes/hermes-agent/skills/
```

Agent 根据描述自动匹配适合的技能执行。

## 技能市场

Hermes 官方提供技能市场（agentskills.io），支持导入社区技能：

```bash
hermes skills install <skill-name>
```

## 与 OpenClaw Skills 的差异

| 维度 | Hermes | OpenClaw |
|------|--------|----------|
| 格式 | SKILL.md + scripts | SKILL.md + scripts |
| 触发方式 | 语义/关键词自动匹配 | 关键词匹配 |
| 自改进 | 内置自动优化 | 需手动触发 |
| 存储位置 | ~/.hermes/hermes-agent/skills/ | workspace/skills/ |
