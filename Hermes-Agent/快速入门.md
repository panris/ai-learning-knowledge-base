# Hermes Agent 快速入门

## 前置要求

- Python 3.10+
- uv（推荐）或 pip/conda
- 模型 API Key（支持 OpenRouter、OpenAI、Nous Portal 等）

## 安装步骤

### 自动安装（推荐）

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

### 手动安装

```bash
pip install hermes-agent
# 或使用 uv
uv pip install hermes-agent
```

## 首次启动

```bash
source ~/.bashrc    # 重新加载 shell
hermes              # 启动交互式 CLI
```

## 配置模型

```bash
hermes model        # 交互式选择模型
```

常用配置示例：

```bash
# 使用 OpenRouter（支持 200+ 模型）
hermes config set openrouter.api_key YOUR_KEY

# 使用 Nous Portal
hermes config set nous.api_key YOUR_KEY

# 切换模型
hermes model openrouter:anthropic/claude-3.5-sonnet
hermes model openai:gpt-4o
```

## 基础命令

| 命令 | 说明 |
|------|------|
| `hermes` | 启动交互式 CLI |
| `hermes model` | 选择/切换模型 |
| `hermes tools` | 配置工具权限 |
| `hermes gateway start` | 启动消息网关（后台运行 Telegram 等） |
| `hermes doctor` | 诊断环境问题 |

## 启动消息网关

配合 Telegram、Discord 等平台使用：

```bash
hermes gateway setup   # 配置网关（扫码授权等）
hermes gateway start  # 启动网关
```

网关运行后，可通过对应平台与 Agent 对话，命令与 CLI 互通。

## 常见问题

### 找不到 `hermes` 命令

```bash
source ~/.bashrc
which hermes
```

### 模型连接失败

```bash
hermes doctor
```

### 从 OpenClaw 迁移

```bash
hermes claw migrate
```
